# AssetQ

Submit an asset request with text and attachments, follow a durable job, and retrieve verified results. Versioned methods record how assets are made, what they cost, and why a method is recommended.

Initial examples: an image generated by a capable Codex worker, then an image-to-3D prop through Meshy and headless Blender. Claude image workers require separate capability qualification.

Stage: specification and TaskQ bootstrap; no working generation or deployed storage is claimed.

- [Contract](assetq.md): product decisions and ownership.
- [Architecture](docs/architecture.md): AgentQ/CoreQ boundaries and service execution.
- [Implementation plan](docs/implementation-plan.md): dependencies and rollout.
- [Acceptance](docs/acceptance.md): the two real journeys and failure evidence.
- [3D baseline](docs/meshy-baseline.md): scoped evidence from csgo.

Run `python3 scripts/check.py` with Python 3 and Git. The bootstrap gate fetches only the exact pinned public specq revision into ignored `.specq`; it checks this contract and whitespace. CI also checks PR and merge-queue candidates. Implementation checks must join this command before code is accepted.
