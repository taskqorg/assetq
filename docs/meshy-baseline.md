# Meshy prop baseline from csgo

The source is the csgo project's Blender MCP trial and original prop pipeline at source revision `2dfb1941472a470853bc2edb31a6c09f214ab14a`. The source files were clean at inspection. Private repository locators and original asset payloads stay in restricted PM evidence; this card records the reusable method and scoped observations only.

The trial retained the explicit Meshy CLI/API plus headless Blender route for a prop. Its historical request used `image-to-3d`, `meshy-t2` Smart Topology, target 3000 triangles and 2K PBR. Observed output: 2655 triangles, 15 credits and 23 seconds of provider generation. These observations are not current prices, latency guarantees or a universal model benchmark.

The compared Blender MCP request had no exposed topology/polycount controls, produced 479557 triangles, cost 30 credits and required GUI Blender. The recommendation was to keep the explicit API/CLI and headless route.

Before dispatch, verify current official API support, parameter meanings, available credentials, quota/balance and expected cost. If `meshy-t2` or its parameters are unavailable, report that gap and propose a versioned replacement; never silently request `latest`.

This baseline does not qualify characters, hands, rigging or low-poly likeness. Those require their own use-case tests and recommendation scope.
