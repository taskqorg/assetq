The prior contract limited qualification to non-generating work. It also requires actual native tool/output evidence before image eligibility. A model list cannot bridge that gap. The proposing worker must not silently expand this explicitly non-generating mode or regenerate the accepted crate.

Approved decision: permit one distinct, isolated local qualification job after the remaining slot/preparation/completion implementation and deterministic checks are ready. Submit it through the durable AssetQ API, not a direct paid API or an unrelated image tool. The operator supplies the existing Mac authority; the worker remains responsible for receipts. Owner answer [6604502494](https://github.com/taskqorg/assetq/issues/4#issuecomment-6604502494), retained verbatim: "One bounded job - + real tool/output and durable-path evidence; - consumes a subscription turn; unreported charge stays unknown." The owning contract is amended before implementation (R1/R3/R7). This decision does not prove implementation or native qualification.

- Content: one original stylized blue wooden wedge on a plain background, no text or third-party references. Request one PNG up to 1024 by 1024 pixels. Use a verified invented blue-swatch attachment to exercise the structured-image path; it is input, never an output substitute.
- Effects: one new job/idempotency identity, at most one `Runtime::input`, no client retry or second submission. Do not use the crate's job, operation, generation request or idempotency key. The accepted crate remains the sole initial image-to-3D input.
- Authority: existing project grant, inherited subscription account/model/effort/optimizer and pinned protected adapter. No grant, ordinary configuration, capacity, account or model edit; no alternate worker, production enablement, deployment or service restart.
- Bounds: one concurrent job, at most 600 seconds generating plus 30 seconds observing interruption; existing file/storage/free-space/metadata limits remain enforced. Original PNG at most 64 MiB, journal at most 32 MiB, with the existing temporary reservation. No paid API spend or account purchase. Actual native/tool/backend usage and subscription charge are recorded when reported, otherwise explicitly unknown; they are not asserted to be zero.
- Result: retain native tool and terminal evidence, original artifact path and unchanged bytes, input identities, dimensions/hash/preview, immutable result manifest and authenticated hash-verified retrieval. Exercise duplicate request and control-service interruption against the same operation; no replay. A missing tool refuses precisely and stops. Unknown work keeps reservations until original-operation reconciliation; no successful completion is inferred from transport exit.
