A model list cannot bridge that gap. The proposing worker must not silently expand this explicitly non-generating mode or regenerate the accepted crate.

Submit it through the durable AssetQ API, not a direct paid API or an unrelated image tool. The operator supplies the existing Mac authority; the worker remains responsible for receipts. This is a proposed next action, not an implemented command or a grant inferred from this document.

Original PNG at most 64 MiB, journal at most 32 MiB, with the existing temporary reservation. No paid API spend or account purchase. Actual native/tool/backend usage and subscription charge are recorded when reported, otherwise explicitly unknown; they are not asserted to be zero.
